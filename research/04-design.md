# Дизайн-концепция: «Пудра»

> Направление: **«тихая роскошь» + редакционный журнал**. Много воздуха, крупная антиква, мягкие нюдовые тона,
> один глубокий акцент. Основа — тренды из `01-research.md` (раздел 3).

---

## 1. Палитра «Пудра + бордо»

| Токен | Цвет | Где используется |
|---|---|---|
| `--c-bg` | `#FBF7F3` молочный | Фон страницы |
| `--c-surface` | `#F4ECE6` светлая пудра | Карточки, плитки bento |
| `--c-blush` | `#E8CFC5` пудровый | Декор, подложки, рамки фото |
| `--c-line` | `#E3D6CE` | Тонкие линии, разделители |
| `--c-text` | `#2A2220` тёплый почти-чёрный | Основной текст (контраст ~15:1) |
| `--c-muted` | `#6E5F59` | Подписи, второстепенный текст (контраст ~6:1) |
| `--c-accent` | `#7A2E3A` бордо | Кнопки, ссылки, блок записи (белый текст на нём ~9:1) |
| `--c-accent-hover` | `#5F222C` | Наведение на кнопку |
| `--c-on-accent` | `#FFF8F5` | Текст на бордо |
| `--c-gold` | `#B08D57` | Звёзды рейтинга, мелкие акценты (не для текста) |

Правило: бордо — **только** для действий (кнопки, ссылки) и блока записи. Так глаз сразу находит, куда нажать.

## 2. Типографика

| Роль | Шрифт | Размер (телефон → компьютер) |
|---|---|---|
| H1 (hero) | **Cormorant Garamond** 500, курсив для акцентного слова | 44 → 96 px (`clamp`) |
| H2 (заголовки блоков) | Cormorant Garamond 500 | 34 → 60 px |
| H3 (карточки) | Cormorant Garamond 600 | 22 → 28 px |
| Надзаголовок | **Manrope** 600, ВЕРХНИЙ РЕГИСТР, разрядка 0.14em | 12 → 13 px |
| Текст | Manrope 400 | 16 → 18 px, межстрочный 1.6 |
| Кнопки | Manrope 600 | 16 px |

Оба шрифта с кириллицей, грузим только кириллицу+латиницу и только нужные начертания.
Приём «журнала»: огромный заголовок рядом с маленькой подписью — сильный контраст масштаба.

## 3. Сетка и отступы
- Контейнер: максимум 1240 px, поля по бокам 20 px (телефон) → 40 px (компьютер).
- Шаг отступов: 4 · 8 · 12 · 16 · 24 · 32 · 48 · 64 · 96 · 128 px.
- Между блоками: 80 px (телефон) → 140 px (компьютер).
- Скругления: 8 px (поля), 20 px (карточки), 999 px (кнопки-«пилюли»), фото в hero — арка (скругление сверху).

## 4. Компоненты
- **Кнопка основная:** бордо, светлый текст, пилюля, высота 52 px, при наведении темнеет и чуть приподнимается.
- **Кнопка вторичная:** прозрачная с тонкой рамкой цвета текста.
- **Карточка:** фон `--c-surface`, без теней (плоско и чисто), скругление 20 px.
- **Bento-плитка:** разные размеры в сетке 6 колонок; на телефоне — в одну колонку.
- **Поля формы:** высота 52 px, рамка `--c-line`, фокус — рамка бордо + мягкое кольцо.
- **Вкладки прайса:** пилюли, активная — бордо.
- **Строка прайса:** название слева · пунктирная линия · цена справа (как в меню ресторана).

## 5. Фото
- Тёплые, светлые, крупные планы рук. Hero — вертикальное фото в «арке».
- Мастера — **ч/б**, при наведении — цвет (решает проблему разных по стилю портретов).
- Все фото: AVIF/WebP, адаптивные размеры, правильные `alt` на русском.

## 6. Анимации (сдержанно)
- Появление блоков при прокрутке: сдвиг на 24 px + прозрачность, 600 мс, каскадом.
- Hero: заголовок, текст и кнопки появляются по очереди при загрузке.
- Наведение: кнопки, лёгкий зум фото в галерее (1.04).
- `prefers-reduced-motion` — все анимации отключаются.
- Никакого 3D, параллакса, кинетики.
